# DG West Floor Guide

A floor-by-floor guide to DG West, Sports Road, Westlands, Nairobi. Hover the tower elevation, click a floor to open its plan, then click a home to see its room sizes.

- Plans redrawn from the developer's brochure (floors 5–24 and the 25th floor), at the room sizes printed on them
- Real photographs only (Nairobi skyline and comparable interiors, via Unsplash; none show DG West, which is under construction)
- Single static `index.html`, no build step. Deploy on Vercel with the framework preset set to **Other**.

Independent guide; not affiliated with Reportage Group.
